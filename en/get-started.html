Licensing

The license is not the hard part.

You get the distribution bundle and a token file named takeany.license.
Drop it into the host config directory and start. No online activation, no portal, no seat reconciliation before you can run your first workflow.

Read the full terms →
How it stays live
The token renews itself in the background, twice daily before expiry
One outbound HTTPS connection to the licensing server — no prompts or documents travel over it
Status, validity dates and a manual refresh button sit in Mission Control
An active license also opens the distribution endpoints for updates and microVM components
