Licensing and onboarding

Transparent licensing, automatic renewal

The TakeAny.AI licensing model cleanly separates commercial billing terms from host-level technical access. Your production instances run continuously without manual administrative intervention.

01 · Delivery

Package delivery and key file setup

On purchasing a plan you receive the software distribution bundle along with an initial digital access token file, takeany.license. It is stored directly in the host machine’s local configuration directory: /home/ai/.config/takeany/secrets/takeany.license.

02 · Renewal

Mandatory outbound connection

To maintain continuous operation, your TakeAny.AI instance requires an outbound connection to the dedicated licensing server lic.agentharness.download. The system validates and renews the local technical token in the background, retrying up to twice daily prior to expiration, which eliminates service disruptions.

03 · Updates

Access to the distribution servers

An active licence grants authorised access to the official distribution servers: the latest TakeAny.AI binaries, platform dependencies, helper modules and Firecracker microVM host component updates.

04 · Control

Full visibility in Mission Control

The Mission Control admin dashboard (Settings › License) shows your license ID, current token validity dates, issuer information and connection status. Administrators can trigger an immediate manual token refresh with “Renew token now”.
